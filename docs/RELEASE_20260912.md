# Релиз каталога 2026-09-12

Изменения: расширенные DTO товаров и справочники, фильтры по новым характеристикам,
редактирование в админке, единая шкала вкуса 1–5, вывод характеристик на витрине,
импорт SimpleWine и фотографий через API, лимит фото 10 МиБ.

Публикация приложения не переносит локальную БД, пользователей, заказы, корзины или
10 импортированных вин. Очистка локального каталога не является частью релиза.

GitHub Actions выполняют деплой при push в main. Сначала обновляется backend,
затем admin frontend и storefront. Серверный flock сериализует развёртывания.
Перед миграциями скрипт scripts/deploy/migrate-catalog.sh сохраняет и проверяет
полный pg_dump в ~/backups/domsommelier (доступ только владельцу).
Миграции добавляют JSONB-поля, справочники и индексы; удаления данных нет.

## Ручное применение на существующем сервере, если Actions не имеет SSH-доступа

```bash
set -e
cd ~/projects/domsommelier-backend
git pull --ff-only origin main
cd ~/projects/domsommelier-admin-frontend
git pull --ff-only origin main
cd ~/projects/domsommelier-frontend
git pull --ff-only origin main
cd ~/projects/domsommelier-backend
# В .env: SPRING_PROFILES_ACTIVE=docker,prod и DB_INIT_MODE=false.
# Сначала сборка: при её ошибке работающие контейнеры остаются нетронутыми.
docker compose build domsommelier-app domsommelier-admin-frontend domsommelier-frontend
bash scripts/deploy/migrate-catalog.sh
docker compose up -d --no-deps domsommelier-app
# Дождаться успешного HTTP 200 от API перед обновлением интерфейсов.
timeout 180 sh -c 'until curl -fsS http://localhost:8080/api/v1/filters >/dev/null; do sleep 3; done'
docker compose up -d --no-deps domsommelier-admin-frontend domsommelier-frontend
docker compose ps
curl -fsS http://localhost:8080/api/v1/filters >/dev/null
```

Перед ручным развёртыванием убедиться, что GitHub Actions не выполняет деплой.
Если установлен только docker-compose, использовать его вместо docker compose.
Не выполнять down -v. В случае ошибки миграции/старта остановить развёртывание
и сохранить журнал и резервную копию. Аддитивная схема позволяет вернуть
предыдущий образ приложения без удаления новых колонок.
